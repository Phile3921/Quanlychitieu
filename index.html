Đồng bộ PC & Điện thoại (File dữ liệu)

Dữ liệu được lưu an toàn trực tiếp trên trình duyệt của bạn. Để chuyển dữ liệu giữa máy tính và điện thoại, hãy xuất file JSON và nhập lại trên thiết bị kia.

Cách tạo lối tắt như App trên điện thoại

  • iPhone (Safari): Mở link GitHub Pages của bạn bằng Safari → Nhấn nút Chia sẻ (Share) ở thanh dưới cùng → Chọn Thêm vào MH chính (Add to Home Screen).
  • Android (Chrome): Mở link bằng Chrome → Nhấn dấu 3 chấm góc trên bên phải → Chọn Cài đặt ứng dụng (Install app) hoặc Thêm vào màn hình chính.
